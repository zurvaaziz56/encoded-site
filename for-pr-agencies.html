The system we run for an agency today

One of those six is not a proposal. It has been running in production for a PR agency, week in and week out. Here is what it does.

Case 01 · PR agency 📰
The problem
Every piece needed a full reread before it went out. The AI drafts broke house style somewhere different each time, so nobody could trust them unchecked. The checking fell to the person with the least time.
What the system does
An 8-stage editorial check runs on each piece, around 20 checks per piece, in weekly batches. Each stage looks for a different class of problem, in the same order every time.
What they get
The checking happens before the work reaches a person. What arrives on an editor's desk has already been through every check the agency would have run by hand.
What stayed with people
Every judgment call. The system flags and fixes what it can prove is wrong against the rules. It does not decide whether a story is any good.
